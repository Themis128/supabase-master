# Build in a weekend. Scale to millions.

Supabase is the Postgres development platform. Start your project with a
Postgres database, Authentication, instant APIs, Edge Functions, Realtime
subscriptions, Storage, and Vector embeddings.

## Products

- Database
- Auth
- Edge Functions
- Realtime
- Storage
- Vector
- Data APIs

## Dashboard Features

- Table Editor: Manage your data with the familiarity of a spreadsheet
- SQL Editor: In-built SQL editor for when you need greater control
- RLS Policies: User management as straight-forward as it can be
